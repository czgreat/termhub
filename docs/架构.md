# 架构

termhub 由 Hub、节点上的 agent（Windows 或 Linux）和网页组成。

- Hub（cmd/termhub、internal/hub）：账号和权限、节点登记、WebSocket 转发、SQLite 元数据、内嵌网页。
- Agent（cmd/termhub-agent、internal/agent）：以安装用户运行，主动连接 Hub，校验 Hub 证书指纹。节点令牌在 Windows 上用该用户的 DPAPI 保护；在 Linux 上用由 machine-id 和 uid 派生的密钥加密，并要求文件只有本用户可读（见 [Linux 节点](Linux节点.md)）。
- 会话宿主（internal/host、internal/session）：拥有伪终端（Windows 上是 ConPTY，Linux 上是 POSIX 伪终端）和子进程，与 agent 的连接进程分开；关闭浏览器或仅重启 agent 连接进程不结束会话。节点重启或宿主退出会结束会话。
- 历史记录（internal/agent/history）：只读扫描官方 CLI 文件；Hub 保存用户自己的隐藏、文件夹显示名等元数据，不改官方记录。
- 网页（web/src）：Svelte 5、xterm.js，支持桌面分屏、手机输入工具栏、历史记录、PWA。
- 通信格式在 internal/proto；会话和文件权限在 Hub 校验，节点按安装用户的操作系统权限访问文件。

节点支持 Windows 和 Linux，不支持 macOS；Linux 节点目前只能从源码构建。没有自动升级和托盘程序。程序会保留回放所需的终端数据；不要把它当作不留痕的安全工具。

开发入口见 AGENTS.md；部署见部署指南.md；信任边界与备份见安全说明.md。
