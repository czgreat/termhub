# 架构

termhub v0.1.0 由 Hub、Windows agent 和网页组成。

- Hub（cmd/termhub、internal/hub）：账号和权限、节点登记、WebSocket 转发、SQLite 元数据、内嵌网页。
- Agent（cmd/termhub-agent、internal/agent）：以安装用户运行，主动连接 Hub，校验 Hub 证书指纹。节点令牌使用该用户的 Windows DPAPI 保护。
- 会话宿主（internal/host、internal/session）：拥有 ConPTY 和子进程，与 agent 的连接进程分开；关闭浏览器或仅重启 agent 连接进程不结束会话。Windows 重启或宿主退出会结束会话。
- 历史记录（internal/agent/history）：只读扫描官方 CLI 文件；Hub 保存用户自己的隐藏、文件夹显示名等元数据，不改官方记录。
- 网页（web/src）：Svelte 5、xterm.js，支持桌面分屏、手机输入工具栏、历史记录、PWA。
- 通信格式在 internal/proto；会话和文件权限在 Hub 校验，节点按安装用户的操作系统权限访问文件。

本版节点只支持 Windows。自动升级、托盘、出口 IP 监控均不属于本版功能。程序会保留回放所需的终端数据；不要把它当作不留痕的安全工具。

开发入口见 AGENTS.md；部署见部署指南.md；信任边界与备份见安全说明.md。
